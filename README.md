# VisioFiltro Beta para Android

[Baixar o APK do VisioFiltro Beta](https://github.com/luisagoetten/visiofiltro-downloads/releases/download/v1.4.4-beta.1/VisioFiltro-1.4.4-beta.1.apk)

O VisioFiltro aplica uma camada de cor sobre a tela. Esta versão de teste inclui seis cores, tom claro ou escuro, intensidade ajustável e atalho pelo widget ou pelas Configurações rápidas. Os filtros são gratuitos e a versão beta funciona sem anúncios e compras.

Requer Android 7.0 ou mais recente. Abra o APK no aparelho e, se o Android pedir, permita a instalação pelo navegador ou gerenciador de arquivos que você usou para abri-lo. Na primeira ativação, conceda a permissão de sobreposição pela tela do Android.

Para relatar problemas, envie o modelo do aparelho, a versão do Android e os passos para reproduzir para girassolestudiodigital@gmail.com.
